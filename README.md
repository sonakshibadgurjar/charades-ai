# 🎬 AI Dumb Charades

An AI-powered Dumb Charades game that attempts to guess movies based on user actions and gestures.

---

## 📌 Problem Statement

Traditional dumb charades relies entirely on human guessing.

This project explores how Artificial Intelligence can observe human actions and attempt to predict the movie being acted out.

---

## 💡 Solution

The system captures user actions and sends action descriptions to an AI-powered guessing engine.

The AI then predicts the most likely movie title.

## 🚀 How It Works

1. User performs an action.
2. Camera captures movement.
3. Action is interpreted.
4. AI guessing engine receives action.
5. Movie prediction is generated.
